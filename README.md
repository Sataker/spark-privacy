# Spark and Viteon: public compliance pages

Public pages required by the Meta platform and the Brazilian LGPD. Keep these URLs stable, because they are registered in app settings.

- `index.html`: data deletion instructions, live at https://sataker.github.io/spark-privacy/
- `viteon/index.html`: Viteon institutional page, live at https://sataker.github.io/spark-privacy/viteon/

No build step: GitHub Pages serves these files directly from `main`. To preview locally, run `python3 -m http.server` and open http://localhost:8000.
